# 🥣 MakePit

**MakePit** — это веб-приложение, которое помогает осознанно подходить к питанию.  
Комбинируй продукты, формируй блюда и сразу смотри аналитику по **КБЖУ** и процентам **Б/Ж/У** от общей калорийности.

---

## 🚀 Возможности

⚡ **Конструктор рациона** — добавляй продукты и смотри суммарные КБЖУ.  
📊 **Аналитика** — визуальное отображение долей белков, жиров и углеводов.  
🍽 **Комбинации продуктов** — подбирай сочетания по нутриентам.  
🧮 **Автоматический пересчёт** — мгновенно обновляет данные при изменении количества продукта.  

---

## 🧠 Цель проекта

Делал для себя и друзей — надоело вести питание в блокноте вручную.  
Теперь всё автоматически и наглядно.
